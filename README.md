## О проекте

Этот репозиторий — статическая версия сайта-визитки/портфолио:
- **HTML + CSS**
- **без сборки** (никакого npm, webpack и т.п.)
- адаптивная верстка (комфортно на десктопе и мобильных)
- единая тема и компоненты (карточки, кнопки, сетки) в `styles.css`
- изображения/иконки/GIF находятся в `assets/`

---

## Страницы

- `index.html` — **Главная** (hero, блоки превью, контакты)
- `projects.html` — **Проекты** (карточки проектов + блоки фич/направлений)
- `about.html` — **Обо мне** (описание, стек/процессы, контакты)
- `admin.html` — **Админка** (страница с GIF по центру)
